# KayKit free packs (backup)

This branch only stores the source asset packs for Henstead. The game lives on the `main` branch.

These are the free tier of every KayKit pack by Kay Lousberg (www.kaylousberg.com), downloaded from kaylousberg.itch.io in November 2026. Each is licensed CC0; the licence file is inside each zip. Credit to Kay Lousberg is appreciated but not required. The paid EXTRA and SOURCE tiers are not included: buy them on itch.io to support the creator.

To use them: unzip the packs into one folder, then from the game repo run
`KAYKIT_DIR=that/folder python3 tools/pack_models.py tools/models.json assets/models`
after adding the models you want to `tools/models.json`.

To fetch only this branch: `git clone --single-branch --branch kaykit-packs https://github.com/jessedavies/henstead kaykit-packs`
